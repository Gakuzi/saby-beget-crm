# Инструкция по развертыванию на собственном VPS

CRM-система полностью готова к установке на ваш личный сервер. 
В качестве базы данных используется **SQLite** — это полноценная реляционная SQL-база, которая хранит данные в файле `data/crm_server.sqlite3`. При работе на вашем сервере этот файл **никогда не удалится**, в отличие от песочницы разработчика.

## Быстрая установка (Автоматически)

1. Зайдите на ваш VPS по SSH (потребуется Ubuntu/Debian).
2. Выполните команду скачивания и запуска скрипта установки:
   ```bash
   curl -O https://raw.githubusercontent.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ/main/deploy/install.sh
   chmod +x install.sh
   sudo ./install.sh
   ```
3. Скрипт попросит ссылку на ваш репозиторий (куда вы синхронизировали код из CRM).
4. CRM развернется через Docker и будет доступна по IP вашего сервера.

## Ручная установка (Docker)

Если вы хотите развернуть вручную:

1. Склонируйте ваш репозиторий:
   `git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git saby-crm`
2. Перейдите в папку:
   `cd saby-crm`
3. Скопируйте `docker-compose.yml` из папки `deploy/` в корень:
   `cp deploy/docker-compose.yml .`
4. Запустите:
   `docker compose up -d`
