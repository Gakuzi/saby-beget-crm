# Личный кабинет клиента - Климов CRM

## Обзор

Разработан полноценный личный кабинет для клиентов на основе предоставленных эскизов из папки `image/`.

### Файлы эскизов:
- `klimov-crm-client-portal-overview.PNG` - Главная страница с обзором
- `klimov-crm-client-portal-events.PNG` - Страница событий
- `klimov-crm-client-portal-report.PNG` - Страница отчётов

## Реализованный функционал

### 1. Шаблон личного кабинета (`templates/client_portal.html`)

Современный адаптивный интерфейс с тремя основными разделами:

#### 📊 Обзор (Overview)
- Информация о компании (название, ИНН, договор, сайты)
- Последние 5 событий из timeline
- Быстрые действия (сформировать отчёт, связаться)

#### 📅 События (Events)
- Полная история событий в формате timeline
- Три типа событий с цветовой индикацией:
  - 🔵 Работы (work_log)
  - 🟠 События хостинга (host_event)
  - 🟢 Бэкапы (backup)
- Детальная информация по каждому событию

#### 📈 Отчёты (Report)
- Форма выбора периода для формирования отчёта
- Список сохранённых отчётов (готов к интеграции)
- Возможность скачивания отчётов

### 2. Серверная часть (`app.py`)

Обновлён маршрут `/public/client/<token>`:
- Получение полной информации о клиенте (ИНН, договор, сайты)
- Построение полного timeline событий
- Интеграция с базой данных work_logs
- Интеграция с backups.db (хостинг события и бэкапы)
- Передача данных в новый шаблон

## Дизайн-особенности

- **Стеклянный морфизм** - карточки с backdrop-filter blur
- **Градиенты** - современные градиентные фоны и кнопки
- **Адаптивность** - полная поддержка мобильных устройств
- **Навигация через табы** - переключение между разделами без перезагрузки
- **Пустые состояния** - красивые заглушки при отсутствии данных

## Как использовать

1. Администратор создаёт ссылку доступа для клиента через карточку клиента
2. Клиент получает URL вида: `https://your-domain.com/public/client/<token>`
3. Клиент переходит по ссылке и видит свой личный кабинет
4. Клиент может:
   - Просматривать информацию о своей организации
   - Видеть историю работ, событий хостинга и бэкапов
   - Формировать отчёты за выбранный период

## Технические детали

- Flask template: `render_template('client_portal.html', ...)`
- Все данные передаются через Jinja2 переменные
- JavaScript для переключения табов без перезагрузки страницы
- CSS с использованием современных свойств (backdrop-filter, grid, flexbox)

## Структура данных timeline

```python
{
    'type': 'work_log'|'host_event'|'backup',
    'ts': timestamp,
    'human': 'человекочитаемая дата',
    # Для work_log:
    'description': 'описание работ',
    'hours': количество часов,
    # Для host_event:
    'event_type': 'тип события',
    'source': 'источник',
    'details': детали,
    # Для backup:
    'site_name': 'имя сайта',
    'site_domain': 'домен',
    'size_mb': размер в МБ,
    'status': 'статус'
}
```
