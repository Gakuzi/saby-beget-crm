# Интеграция с СБИС (Saby) - Руководство по тестированию

## ✅ Что реализовано

### 1. Модуль интеграции (`saby_integration.py`)
- Авторизация в Saby API через сервисный ключ
- Поиск организаций по ИНН
- Получение договоров по регламенту "Аутсорсинг"
- Загрузка выполненных работ из актов
- Загрузка обращений клиентов
- Загрузка документов (счета, акты)
- Ежедневная автоматическая синхронизация

### 2. Веб-интерфейс (`app.py`)
- Главная страница со списком клиентов
- Страница добавления контрагента с поиском в Saby
- Карточка клиента с 4 вкладками:
  - 📋 **Работы из Saby** - выполненные работы из актов
  - 📞 **Обращения** - задачи и обращения клиентов
  - 📄 **Документы** - счета и акты с статусами
  - ✏️ **Локальные записи** - ручное добавление работ
- Кнопка ручной синхронизации с Saby
- Генерация отчетов за период

### 3. База данных (`crm_data.db`)
Таблицы для хранения данных из Saby:
- `saby_works` - выполненные работы
- `saby_requests` - обращения клиентов
- `saby_documents` - документы (акты, счета)
- `sync_log` - журнал синхронизаций

### 4. API Endpoints
- `POST /api/saby/sync/<client_id>` - ручная синхронизация
- `GET /suggest_company?q=<query>` - поиск организаций
- `GET /get_contracts?inn=<inn>` - получение договоров

## 🧪 Тестирование

### Вариант 1: Быстрый тест через скрипт
```bash
cd /workspace && python3 visual_test.py
```
Этот скрипт:
- Проверит структуру таблиц БД
- Добавит тестового клиента (если нет)
- Выведет инструкцию по запуску

### Вариант 2: Полный тест веб-интерфейса

1. **Запустите Flask-приложение:**
   ```bash
   cd /workspace && python3 app.py
   ```
   Приложение запустится на порту 3002

2. **Откройте главную страницу:**
   ```
   http://localhost:3002
   ```

3. **Добавьте контрагента через поиск Saby:**
   - Перейдите на `/add_page`
   - Введите ИНН организации (например, ваш ИНН)
   - Выберите договор из списка
   - Сохраните

4. **Проверьте карточку клиента:**
   - Откройте `/client/<ID>`
   - Переключайтесь между вкладками
   - Нажмите "🔄 Синхронизировать с Saby"
   - Проверьте появление данных

5. **Проверьте API синхронизации:**
   ```bash
   curl -X POST http://localhost:3002/api/saby/sync/1 | python3 -m json.tool
   ```

## ⚠️ Возможные проблемы

### Ошибка "Неверный формат даты"
Если видите ошибку вида:
```
Неверный формат значения '2026-07-19' для поля с датой 'ДатаС'
```
Это значит, что дата в будущем. Saby не принимает даты больше текущей.
Решение: проверьте системное время или параметры запроса.

### Нет договоров при поиске
- Убедитесь, что у организации есть активные договоры по регламенту "Аутсорсинг"
- Проверьте, что сервисный ключ имеет доступ к документам
- ИНН должен быть указан точно

### Пустые таблицы после синхронизации
- Проверьте логи синхронизации в таблице `sync_log`
- Убедитесь, что в Saby есть данные за последний период (30 дней для работ, 90 для счетов)

## 🔄 Автоматическая синхронизация

Для настройки ежедневной синхронизации добавьте в crontab:
```bash
# Ежедневно в 02:00
0 2 * * * /usr/bin/python3 /workspace/saby_integration.py >> /var/log/saby_sync.log 2>&1
```

Или используйте готовый скрипт:
```bash
/opt/backup-reports/saby_daily_sync.sh
```
