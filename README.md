## 📌 О проекте

Эта CRM-система разработана для автоматизации работы IT-специалистов, системных администраторов и бухгалтеров на аутсорсинге. Она объединяет в себе:
- Синхронизацию договоров и контрагентов из **СБИС (Saby)**.
- Управление серверами и хостингом через API **Beget**.
- Локальную защищенную базу данных **SQLite**.
- Встроенный Web-терминал для доступа по SSH прямо из браузера.
- Систему авторизации **WebAuthn (FaceID/TouchID)**.
- Автоматизированное создание бэкапов.

## 🚀 Возможности системы

1. **Единая база клиентов:** Поиск и автозаполнение карточек по ИНН прямо из базы СБИС.
2. **Безопасность:** Вход по паролю или через **Passkey** (аппаратные ключи, отпечатки пальцев).
3. **SSH-клиент в браузере:** Мгновенный доступ к консоли VPS клиента без сторонних терминалов.
4. **Уведомления:** Встроенный почтовый SMTP-модуль для рассылок и отчетов.
5. **CI/CD и GitHub Sync:** CRM умеет сама сохранять свой исходный код и бэкапы на GitHub (коммиты прямо из интерфейса).
6. **Автоматическое резервное копирование:** Скрипты агентов, которые можно в один клик закинуть на сервер клиента.

## 🛠️ Как установить (Развертывание на VPS)

Проект полностью контейнеризирован и готов к запуску на любом Ubuntu/Debian сервере. 
Вам понадобится только установленный `curl` (или `git`).

### Шаг 1. Автоматическая установка (Рекомендуется)

Войдите на ваш VPS по SSH от имени `root` и выполните команду:
\`\`\`bash
curl -O https://raw.githubusercontent.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ/main/deploy/install.sh
chmod +x install.sh
sudo ./install.sh
\`\`\`
*(Скрипт сам установит Docker, загрузит CRM, создаст папку для базы данных и запустит систему)*

### Шаг 2. Ручная установка (через Docker Compose)

1. Клонируйте репозиторий:
   \`\`\`bash
   git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git saby-crm
   cd saby-crm
   \`\`\`
2. Запустите Docker Compose:
   \`\`\`bash
   cp deploy/docker-compose.yml .
   docker-compose up -d
   \`\`\`
3. Откройте IP-адрес вашего сервера в браузере.

## ⚙️ Первичная настройка (Как это работает)

Сразу после первого запуска вам нужно настроить интеграции. Перейдите в **«⚙️ Настройки Saby»** (в верхней панели).

1. **Saby (СБИС):**
   * Введите \`app_client_id\` и \`app_secret\`.
   * Загрузите защищенный ключ (сертификат \`.key\`).
   * Нажмите «Проверить связь».
2. **Хостинг Beget:**
   * Введите логин аккаунта.
   * Сгенерируйте и вставьте пароль от API в панели Beget.
3. **Почта (SMTP):**
   * Введите реквизиты почтового ящика (например, \`smtp.beget.com\`, порт \`465\`).
   * CRM будет использовать его для отправки логов и алертов о бэкапах.

## 📂 Структура проекта

* \`server.js\` — Главный backend-файл (Express.js сервер).
* \`sqlite_db.js\` — Драйвер локальной базы данных (Better-SQLite3).
* \`saby_client.js\` / \`beget_client.js\` — Модули интеграции по API.
* \`admin_view.js\` — Интерфейс администратора (Рендер HTML/UI).
* \`deploy/\` — Docker-файлы и bash-скрипты для легкой установки.
* \`data/\` — Папка (генерируется автоматически), где лежит файл базы данных \`crm_server.sqlite3\`.

## 🛡️ Создание релизов

В проекте настроена автоматическая синхронизация с GitHub (см. \`github_sync.js\`). 
Для создания новой версии:
1. Внесите изменения в логику.
2. В интерфейсе CRM нажмите иконку **🐙 GitHub** и сделайте push.
3. Перейдите во вкладку **Releases** на GitHub и создайте новый релиз, привязав его к последнему коммиту. 

> Разработано с использованием Node.js, Express, и SQLite.
